# Legacy evidence only

Todo conteúdo abaixo de `legacy/` é histórico e não normativo.

- Não editar arquivos V1.
- Não copiar arquitetura, provider ou schema da V1 para código novo.
- Não usar protótipos V1 como design aprovado.
- Em conflito, prevalecem `ARCHITECTURE_CONSTITUTION.md`, contratos V2, ADRs V2 e task graph.
- O conteúdo é preservado apenas para auditoria, rastreabilidade e hashes.
