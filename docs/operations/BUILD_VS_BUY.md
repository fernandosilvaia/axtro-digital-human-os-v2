# Build vs Buy

| Component | Agora | Depois | Justificativa |
|---|---|---|---|
| WebRTC/SFU | buy/use OSS abstraction | self-host only with scale reason | commodity, operationally hard |
| STT/TTS/S2S | provider adapters | optimize routing | quality evolves rapidly |
| Avatar generation | provider | own model only at large scale | high research and GPU cost |
| Meeting bots | provider | own adapter if economics justify | platform breakage burden |
| Sales state and Role Packs | build | deepen | core differentiation |
| Action and policy runtime | build | enterprise controls | authority is core moat |
| Behavior and Scene directors | build | richer models | experience differentiation |
| Axtro control plane | build | autonomy and marketplace | strategic asset |
| Workflow engine | integrate | retain abstraction | durable execution is commodity |
| Evaluation and learning governance | build on tools | expand datasets | proprietary quality loop |
| Database and auth | managed initially | dedicated enterprise later | speed and reliability |
